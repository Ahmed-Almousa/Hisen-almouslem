# Hisn Al-Muslim

This repository contains a Flutter UI preview for the app idea "حصن المسلم | Hisn Al-Muslim".

## Features in this preview
- Bottom navigation
- Home screen
- Adhkar screen
- Prayer times screen
- Qibla screen
- More screen
- Settings screen
- Sample cards and design mockup

## Run locally
```bash
flutter pub get
flutter run
```

## Preview on GitHub Pages
This app can be published as a Flutter web preview using GitHub Pages.

After the workflow runs, the preview will be available at:

https://ahmed-almousa.github.io/Hisen-almouslem/

## Notes
This is a UI preview only. It does not yet include the full production architecture, real content sources, prayer calculation engine, or notification system.
